# 抖音直播录制工具V2

> **当前版本：2.13.29**

基于 Electron 的抖音直播录制桌面工具，采用 **流媒体直录 + 离屏评论区渲染** 架构，实现高质量音视频录制，并可拼接右侧评论区弹幕、左侧特效区与团播榜单，支持 Windows 系统。

## 功能特性

### 录制与画质
- **高质量录制**：FFmpeg stream copy 直接录制直播流，保留原始音视频质量，零损耗
- **评论区拼接**：离屏窗口捕获直播间右侧评论区（弹幕），合成到最终视频右侧
- **左侧特效区**：可同步捕获左侧信息面板（主播信息、礼物榜、观众列表等），三区域拼接
- **团播榜单**：团播直播间自动展开"团员榜单/本场成员"并扩宽评论区捕获区域，将榜单完整录进视频
- **实时时间戳**：评论区顶部实时显示录制日期时间（YYYY-MM-DD HH:MM:SS），每秒刷新，便于后期定位
- **抗中断封装**：分片 MP4（fragmented MP4）封装，流中断/进程强杀后已录内容仍可播放

### 稳定与自愈
- **三路时间轴统一**：评论区/特效区按逐帧真实时间戳编码（VFR 保真），与源视频起点偏移对齐、统一目标时长截断——三路内容不漂移、不错位
- **流重启分段保护**：视频轨停滞/时间戳回绕触发的 URL 刷新重启时，新进程直写新分段文件（stream_partN.mp4），**已录内容绝不覆盖**，合并时按序自动拼接
- **断线重录**：直播流中断后自动重新检测，若仍在直播则立即继续录制（场次自动分割）
- **账号冲突回滚**：同一账号被多个直播间共用被顶下线时，自动回滚为「无账号+评论区」继续录制，评论区不中断
- **合并失败兜底**：评论/特效区编码失败自动降级重试，合并异常保留标准化源视频，绝不空手而归
- **崩溃合并恢复**：合并中途程序崩溃/断电，下次启动检测到未完成合并任务可自动恢复续作

### 自动化与管理
- **智能监控**：自动检测直播状态，开播自动录制、下播自动停止
- **多直播间**：同时添加多个直播间，独立监控与录制
- **多账号支持**：可登录多个抖音账号，为每个直播间自由指定录制账号（未指定则用默认主账号）
- **链接解析**：粘贴抖音分享文本自动提取直播间链接与主播名称；主播改名后列表自动同步
- **手动合并工具**：支持将已保存的源视频/评论区视频（或帧目录）手动重新合并，用于补救与再加工
- **任务栏/托盘角标**：最小化后实时显示录制/合并中的房间数，点击关闭按钮最小化到托盘（不退出）

| 模式 | 直播画面 | 评论区 | 左侧特效区 | 团播榜单 | 需要账号 |

| 仅录制直播流 | ✓ | — | — | — | 否 |

| 有账号录制 | ✓ | ✓ | — | — | 是 |
| 有账号+评论区 | ✓ | ✓ | — | — | 是 |

## 架构设计

### 录制流程（两阶段）

```
Phase 1（录制中）:
  直播流 URL ──→ FFmpeg (stream copy, 分片MP4) ──→ stream.mp4（原始音视频）
                 └ 流重启时分段直写 stream_partN.mp4（不覆盖旧内容）
  直播间页面 ──→ Electron 离屏窗口 ──→ 评论区帧序列 + 左侧特效区帧序列（JPEG）
                 └ 每帧记录真实捕获时间戳（timestamps.json）
                 └ 评论区顶部注入录制时间戳显示

Phase 2（录制结束后）:
  ① 分段流文件按序 concat 拼接（stream copy，不重编码）
  ② 评论/特效区帧按逐帧时间戳经 concat demuxer 编码（VFR 保真）
  ③ setpts 起点偏移对齐 + tpad 末帧补齐 + 统一目标时长截断
  ④ FFmpeg overlay 三区域拼接 → final.mp4
     布局: [左侧特效区 | 直播画面 | 2px分隔线 | 评论区（可含团播榜单）]
  ⑤ 同时保存标准化源视频 / 评论区视频 / 特效区视频中间产物
```

### 核心模块

| 模块 | 文件 | 职责 |
|------|------|------|
| 主进程 | `main.js` | Electron 主进程、IPC 桥接、合并恢复、任务栏/托盘角标 |
| 预加载脚本 | `preload.js` | 安全暴露 API 给渲染进程 |
| 录制引擎 | `src/lib/recorder.js` | FFmpeg 流录制、分段保护、三路时间轴合并、账号回滚 |
| 评论区渲染器 | `src/lib/comment-renderer.js` | 离屏捕获评论区/特效区帧、团播榜单展开、时间戳显示 |
| 直播间管理 | `src/lib/stream-manager.js` | 生命周期管理、开播检测、账号/模式持久化 |
| 手动合并 | `src/lib/manual-merger.js` | 中间产物/帧目录手动再合并 |
| 配置管理 | `src/lib/config.js` | electron-store 持久化配置 |
| 链接解析 | `src/lib/douyin-utils.js` | 抖音分享链接/短链接解析 |
| 账号管理 | `src/lib/account-manager.js` | 多账号登录、partition 会话管理 |
| 角标生成 | `src/lib/badge.js` | 任务栏/托盘角标 PNG 合成 |

## 安装与运行

### Windows 10/11 打包说明（推荐）

**1. 环境准备**
- 安装 Node.js（推荐 v18+）：https://nodejs.org/
- 安装 pnpm：`npm install -g pnpm`

**2. 解压源代码**
```bash
tar -xzf douyin-recorder-v2.13.29.tar.gz
```

**3. 一键打包**

双击运行 `一键打包.bat`，自动完成环境检查、依赖安装与打包。或手动执行：
```bash
pnpm install
pnpm run build
```

打包完成后：
- 安装包：`dist/抖音直播录制工具V2 Setup 2.13.29.exe`
- 免安装版：`dist/win-unpacked/抖音直播录制工具V2.exe`

### 开发模式

```bash
pnpm install
pnpm run dev        # 启动开发模式（需要桌面环境）
pnpm run build:dir  # 打包为目录（不生成安装包，便于调试）
```

## 使用说明

### 基本流程

1. **登录抖音**：点击「登录抖音」扫码登录；支持登录多个账号（无账号模式可跳过）
2. **添加直播间**：粘贴抖音分享文本或直播间链接，点击添加
3. **选择录制模式与账号**：按需选择六种模式之一，有账号模式可指定录制账号
4. **开启自动录制**：点击「自动录制：关」切换为开启
5. **等待开播**：系统自动检测，开播自动录制、下播自动停止
6. **手动控制**：也可点击「开始录制」/「停止录制」手动控制
7. **合并输出**：录制结束自动合并（直播结束延迟 5 分钟合并防流抖动；手动停止立即合并），期间显示「合并中...」
8. **查看文件**：录制文件保存在 `用户视频/抖音直播录制工具V2/主播名称/` 下

### 支持的链接格式

- 抖音分享文本（自动提取链接）：`"xxx正在直播，快来看看... https://v.douyin.com/xxxxx/"`
- 短链接：`https://v.douyin.com/xxxxx/`
- 直播间链接：`https://live.douyin.com/xxxxx`
- 房间号：直接输入数字房间号

### 输出文件结构

```
用户视频/抖音直播录制工具V2/
└── 主播名称/
    └── 主播名称_2026-11-18_10-17-47/          ← 场次目录（开播时刻）
        ├── 主播名称_2026-11-18_10-17.mp4       ← 最终合并视频
        ├── 主播名称_..._stream.mp4             ← 标准化源视频（纯直播画面）
        ├── 主播名称_..._comments.mp4           ← 评论区视频
        ├── 主播名称_..._effect.mp4             ← 特效区视频（三区域模式）
        └── .temp/                              ← 临时文件（合并成功后自动清理）
```

- **视频布局**：双区域 `[直播画面 | 2px分隔线 | 评论区]`；三区域 `[特效区 | 直播画面 | 分隔线 | 评论区]`
- **分辨率**：直播画面按原始流自适应（通常 1280x720），评论区高度对齐主视频
- 中间产物（_stream/_comments/_effect）可用于「手动合并」再加工

### 手动合并工具

主界面「手动合并」按钮打开：
- 拖入**源视频**（_stream.mp4 或 stream.mp4）
- 拖入**评论区视频**（_comments.mp4，推荐）；或选择评论区帧目录（备选）
- 设置帧率/宽度等参数后开始合并，输出到指定路径

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 输出路径 | 用户视频/抖音直播录制工具V2 | 录制文件保存位置 |
| 检测间隔 | 30 秒 | 直播状态检测间隔 |
| 评论区宽度 | 360 px | 评论区捕获宽度 |
| 评论区帧率 | 15 fps（目标值） | 实际帧率受捕获耗时影响，合并按真实时间戳对齐 |
| 评论区 JPEG 质量 | 92 | 帧压缩质量 |
| 合并 CRF | 15 | 视频编码质量（越小越清晰） |
| 合并预设 | medium | 编码速度预设 |
| 自动录制 | 开 | 检测到开播自动录制 |
| 开机自启动 | 关 | 随系统启动 |
| 关闭最小化到托盘 | 开 | 点关闭不退出程序 |

## 注意事项

### 录制相关
- 录制结束需合并处理，期间显示「合并中...」，请勿强制关闭程序
- 直播结束后**延迟 5 分钟合并**（防止流抖动造成卡顿），手动停止则立即合并
- 合并需要重新编码，CPU 占用较高（可达 80-100%）属正常现象
- 评论区帧率为目标值，实际捕获帧率受页面复杂度影响；**合并按逐帧真实时间戳对齐**，帧率波动不会造成音画错位

### 中断与恢复
- 流中断自动重录会产生新的场次目录（时间戳不同）
- 视频轨停滞/时间戳异常触发的流重启在同场次内完成，分段文件合并时自动按序拼接，内容不丢失
- 程序崩溃/断电后，未完成的合并任务在下次启动时可自动恢复

### 账号相关
- 首次使用建议点击「登录抖音」登录账号，获得完整弹幕与特效区
- 同一账号多直播间共用被顶下线时自动回滚无账号模式，录制不中断

### 其他
- 仅支持 Windows 系统
- 最小化到托盘后仍在监控/录制，退出请右键托盘图标选择退出
