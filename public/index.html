抖音直播录制工具V2

流媒体直录 + 离屏评论区弹幕拼接 | 源码包

打包步骤（Windows 10/11）

1. 安装 Node.js v18+
2. 下载并解压源码 ZIP
3. 双击运行 一键打包.bat
4. 等待 5-10 分钟，自动打开输出目录
5. 运行 dist/ 下的 EXE 安装包

下载源码包

douyin-recorder-source.zip (158 KB)

注意：打包需要联网下载 Electron 等依赖（约 300MB）。
如遇到网络问题，可设置镜像：npm config set registry https://registry.npmmirror.com
